The Apache Wicket PMC is proud to announce Apache Wicket 9.22.0! Apache Wicket is an open source Java component oriented web application framework that powers thousands of web applications and web sites for governments, stores, universities, cities, banks, email providers, and more. You can find more about Apache Wicket at https://wicket.apache.org This release marks another minor release of Wicket 9. We use semantic versioning for the development of Wicket, and as such no API breaks are present in this release compared to 9.0.0. Using this release With Apache Maven update your dependency to (and don’t forget to update any other dependencies on Wicket projects to the same version): <dependency> <groupId>org.apache.wicket</groupId> <artifactId>wicket-core</artifactId> <version>9.22.0</version> </dependency> Or download and build the distribution yourself, or use our convenience binary package you can find here: Download: http://wicket.apache.org/start/wicket-9.x.html#manually
